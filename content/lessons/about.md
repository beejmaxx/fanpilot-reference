# A free reference you can help improve.

Fanpilot is a growing guide to LeetCode patterns, data structures, algorithms, and system design. The goal is independent reasoning: noticing useful structure, choosing a representation, explaining correctness, and adapting when the requirements change.

## What is here today

The working edition contains a 32-chapter patterns guide, 125 linked practice problems, eight Rust examples in that guide, and two interactive design lessons. The data-structures and algorithms pages organize that material. System design begins with LRU cache and file-system design; a full distributed-systems curriculum is still ahead.

The browser labs use JavaScript so you can inspect and change state immediately. The principles are language-independent. They complement the Rust examples and are not presented as production services.

## Read, reconstruct, and challenge

A lesson is a starting point for an attempt. After reading, explain the enabling observation without naming the algorithm. Write the invariant, reconstruct the implementation, and change one assumption. The [transfer exercises](/patterns/transfer-exercises/) and [review worksheet](/patterns/review-pages-and-contribution-method/) support that process.

The [research page](/research/) records which resources informed the guide, what was actually reviewed, and where evidence is indirect. Corrections should improve a claim, example, proof, or test rather than simply add another tag.
